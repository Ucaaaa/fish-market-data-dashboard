# Screenshots

Simpan tangkapan layar hasil aplikasi pada folder ini, misalnya:

- `dashboard-overview.png` — tampilan utama dashboard.
- `dashboard-filter.png` — dashboard setelah filter spesies dipilih.

Cara mengambil screenshot:
1. Jalankan aplikasi dengan `python app.py`.
2. Buka `http://127.0.0.1:5000` di browser.
3. Ambil screenshot tampilan dashboard.
4. Simpan file gambar ke folder ini.
5. Jika sudah ditambahkan, tampilkan gambar di README utama menggunakan Markdown, misalnya `![Dashboard](screenshots/dashboard-overview.png)`.

Folder ini disiapkan sebagai tempat dokumentasi. Tambahkan screenshot asli hasil menjalankan aplikasi sebelum mengumpulkan jika diminta.
